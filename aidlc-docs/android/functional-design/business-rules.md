# Android App — 业务规则

## BR-A1: 认证规则

| 规则ID | 规则描述 |
|--------|---------|
| BR-A1.1 | App 启动时检查本地 Token，有效则直接进入首页 |
| BR-A1.2 | Token 过期或 401 响应 → 清除本地状态 → 跳转登录页 |
| BR-A1.3 | 登录成功存储 Token 和 UserInfo 到 SharedPreferences |
| BR-A1.4 | 所有 API 请求通过 OkHttp Interceptor 自动附加 Bearer Token |
| BR-A1.5 | 登出清除本地所有认证数据 |

---

## BR-A2: 商品浏览规则

| 规则ID | 规则描述 |
|--------|---------|
| BR-A2.1 | 首页显示已上架商品列表，支持下拉刷新 |
| BR-A2.2 | 分类标签水平滚动，首项为"全部" |
| BR-A2.3 | 商品卡片显示: 图片(AsyncImage)、名称、积分价格 |
| BR-A2.4 | 库存为0显示"已兑完"标签 |
| BR-A2.5 | 列表支持分页加载 (page参数) |
| BR-A2.6 | 网络错误显示重试按钮 |

---

## BR-A3: 兑换流程规则

| 规则ID | 规则描述 |
|--------|---------|
| BR-A3.1 | 商品详情页: 积分不足时兑换按钮灰色 + 文案"积分不足" |
| BR-A3.2 | 配送信息页: 收件人(必填)、手机号(必填,11位)、地址(必填) |
| BR-A3.3 | 确认页面显示: 商品名+图片、将扣积分、配送信息摘要 |
| BR-A3.4 | 确认按钮点击后显示 Loading，防止重复提交 |
| BR-A3.5 | 兑换成功显示订单号，可跳转订单详情 |
| BR-A3.6 | 兑换失败 Toast 显示错误原因 |

---

## BR-A4: 订单展示规则

| 规则ID | 规则描述 |
|--------|---------|
| BR-A4.1 | 订单列表按时间倒序 |
| BR-A4.2 | 状态用不同颜色 Chip 标识 |
| BR-A4.3 | 支持按状态筛选 (Tab/Chip) |
| BR-A4.4 | 订单详情显示完整配送信息和状态 |
| BR-A4.5 | 空列表显示友好提示图文 |

---

## BR-A5: 积分展示规则

| 规则ID | 规则描述 |
|--------|---------|
| BR-A5.1 | 积分中心顶部大字显示当前余额 |
| BR-A5.2 | 下方统计: 累计获得 / 累计消费 |
| BR-A5.3 | 积分记录列表: 类型图标 + 积分数(+/-) + 描述 + 时间 |
| BR-A5.4 | 支持按类型筛选 |
| BR-A5.5 | earn/refund 显示绿色(+)，spend/deduct 显示红色(-) |

---

## BR-A6: 网络与错误处理

| 规则ID | 规则描述 |
|--------|---------|
| BR-A6.1 | 网络不可用: 显示 "网络连接失败" + 重试按钮 |
| BR-A6.2 | 请求超时: Toast "请求超时，请重试" |
| BR-A6.3 | 服务器错误(5xx): Toast "系统繁忙" |
| BR-A6.4 | 业务错误: 显示后端返回的 message |
| BR-A6.5 | 401: 自动跳转登录页 |
| BR-A6.6 | 所有列表页支持下拉刷新 |

---

## BR-A7: UI 状态管理

| 规则ID | 规则描述 |
|--------|---------|
| BR-A7.1 | 每个 Screen 使用独立的 ViewModel |
| BR-A7.2 | ViewModel 通过 Hilt 注入 Repository |
| BR-A7.3 | UI State 使用 sealed class 表示: Loading / Success / Error |
| BR-A7.4 | Compose 通过 collectAsState 观察 StateFlow |
| BR-A7.5 | 导航参数通过 SavedStateHandle 传递 |
